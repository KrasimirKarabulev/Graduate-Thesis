# Вградена система за контрол на достъпа с двуканална идентификация (ESP32)

Програмен код към дипломната работа „Проектиране и реализация на вградена система за контрол на достъпа с двуканална идентификация и локално управление на потребителите на базата на микроконтролер ESP32“.

Автор: Красимир Карабулев, ТУ – София, ФКСТ, специалност КСИ, 2026 г.

## Описание

Автономна система за контрол на достъпа до едно помещение, без връзка с мрежа. Вратата се отключва по един от два алтернативни канала:

- **безконтактна карта** (RFID, ISO/IEC 14443A), разпозната по серийния ѝ номер (UID);
- **четирицифрен код**, въведен от матрична клавиатура и потвърден с `#`.

Каналите са алтернативни, а не едновременни (двуканална, а не двуфакторна идентификация).

Основни функции:

- локално управление на потребителите в администраторски режим: добавяне и премахване на карти и кодове, справка за заетостта на паметта, заводско нулиране с потвърждение;
- двустепенен вход в администраторския режим: администраторски код и след него главната карта в рамките на 15 s;
- блокиране на клавиатурата за 60 s след три поредни грешни опита;
- съхранение на картите и кодовете в енергонезависимата памет NVS на ESP32 (библиотека `Preferences`), така че те се запазват след изключване на захранването;
- графичен интерфейс на TFT дисплей 320×240 със светлинна и звукова индикация;
- бутон за изход отвътре (Request-to-Exit, REX).

## Апаратна част

| Елемент | Тип и параметри |
|---|---|
| Микроконтролерен модул | ESP32 NodeMCU-32 (ESP-WROOM-32), 38 извода |
| Понижаващ преобразувател | модул с MP1584EN, 12 V → 3,3 V |
| Безконтактен четец | RFID-RC522 (MFRC522), 13,56 MHz |
| Графичен дисплей | TFT 2,2″, 320×240, контролер ILI9341, интерфейс SPI |
| Матрична клавиатура | пасивна мембранна 4×4 |
| Бутон за изход | PBS28B-2, SPST-NO |
| Електромагнитна брава | соленоидна, 12 V |
| Ключов транзистор и демпферен диод | IRLZ44N; 1N5819 |
| Индикация | зелен и червен светодиод; активен зумер |

Захранването е от един външен източник 12 V. Бравата се управлява от IRLZ44N, а логиката работи на 3,3 V.

## Свързване

| Сигнал | Извод на ESP32 | Посока | Забележка |
|---|---|---|---|
| Редове на клавиатурата | GPIO36, GPIO39, GPIO34, GPIO35 | вход | изводи само за вход; външни повдигащи резистори 10 kΩ |
| Колони на клавиатурата | GPIO19, GPIO18, GPIO21, GPIO32 | изход | |
| SCK | GPIO27 | изход | обща линия на шината SPI |
| MOSI | GPIO26 | изход | обща линия на шината SPI |
| MISO | GPIO25 | вход | само към четеца MFRC522 |
| RFID_CS / RFID_RST | GPIO14 / GPIO33 | изход | избор и нулиране на четеца |
| TFT_CS | GPIO5 | изход | избор на дисплея |
| TFT_DC / TFT_RST | GPIO17 / GPIO16 | изход | команда или данни; нулиране на дисплея |
| LOCK_DRV | GPIO12 | изход | гейт на IRLZ44N (високо ниво = отключено) |
| BUZZ | GPIO13 | изход | активен зумер |
| LED_OK / LED_ERR | GPIO22 / GPIO23 | изход | зелен / червен светодиод |
| REX_BTN | GPIO4 | вход | бутон за изход, активно ниско ниво (`INPUT_PULLUP`) |
| Свободни | GPIO0, GPIO2, GPIO15 | — | резерв |

Подсветката на дисплея е свързана директно към 3,3 V.

## Клавиатура

| Клавиш | Нормален режим | Администраторски режим |
|---|---|---|
| 0–9 | въвеждане на цифра (до четири) | въвеждане на цифра (до четири) |
| `#` | потвърждаване на кода | изход от режима |
| `*` | изчистване на въведеното | справка за заетостта на паметта |
| `A` | — | добавяне на въведения код |
| `B` | изтриване на последната цифра | изтриване на последната цифра |
| `C` | изчистване на въведеното | изчистване на въведеното |
| `D` | — | премахване на въведения код; с администраторския код — заводско нулиране |

Карта се добавя или премахва, като се поднесе към четеца в администраторски режим.

## Програмно осигуряване

- Език: C++ с рамката Arduino за ESP32
- Среда: PlatformIO
- Външни библиотеки (от `platformio.ini`):
  - `miguelbalboa/MFRC522@^1.4.12`
  - `chris--a/Keypad@^3.1.1`
  - `adafruit/Adafruit GFX Library@^1.12.6`
  - `adafruit/Adafruit ILI9341@^1.6.3`
- Вградени в ядрото: `Preferences`, `nvs` / `nvs_flash`, `SPI`

Структура на хранилището:

```
platformio.ini      конфигурация на проекта (платка, рамка, библиотеки)
src/main.cpp        цялата програма
```

## Компилиране и зареждане с PlatformIO

1. Инсталирайте [Visual Studio Code](https://code.visualstudio.com/) с разширението PlatformIO IDE или само PlatformIO Core (CLI).
2. Клонирайте хранилището:
   ```
   git clone https://github.com/KrasimirKarabulev/Graduate-Thesis.git
   cd Graduate-Thesis
   ```
3. Компилирайте. Библиотеките от `lib_deps` се изтеглят автоматично при първото компилиране:
   ```
   pio run
   ```
4. Свържете платката по USB и заредете програмата:
   ```
   pio run -t upload
   ```
5. Отворете серийния монитор (115 200 bps):
   ```
   pio device monitor
   ```

В VS Code същите действия са бутоните Build, Upload и Serial Monitor в долната лента на PlatformIO.

## Бележка

Главният код, администраторският код и серийният номер на главната карта са зададени като константи в началото на `src/main.cpp`. Стойностите в хранилището са на демонстрационния макет. При собствена инсталация те трябва да се сменят преди компилиране.
